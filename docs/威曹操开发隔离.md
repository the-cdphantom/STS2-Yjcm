# 威曹操开发版

同一个 `mod/Yjcm.csproj` 提供两种内容构建，每种都适配稳定版与测试版游戏 API。

| 内容 | 正式版（默认） | 曹操开发版 |
| --- | --- | --- |
| 角色 | 武诸葛亮、威董卓、威曹操 | 武诸葛亮、威董卓、威曹操 |
| MSBuild 开关 | `BuildFlavor=release` | `BuildFlavor=caocao` |
| DLL 暂存 | `artifacts/staged` | `artifacts/caocao/staged` |
| 完整成品 | `artifacts/dist/yjcm` | `artifacts/caocao/dist/yjcm` |
| 可发布 | 是 | 否，清单名称带“曹操开发版” |

从 3.0.0 起，正式包也编译 `mod/src/Experimental/WeiCaoCao`，将 `mod/Experimental/WeiCaoCao` 的场景和本地化合入正式 PCK，并附带 `assets/experimental/WeiCaoCao` 的松散素材。现有资源路径继续使用，两种构建仍分别保存中间产物和成品。

```powershell
# 正式兼容更新
pwsh -NoProfile -File tools/build.ps1 -Variant all
pwsh -NoProfile -File tools/package.ps1
pwsh -NoProfile -File tools/deploy.ps1

# 曹操开发（同时验证正式构建仍然可用）
pwsh -NoProfile -File tools/build-caocao.ps1
pwsh -NoProfile -File tools/package-caocao.ps1
pwsh -NoProfile -File tools/deploy.ps1 -CaoCao
```

本机只安装一种构建到 `mods/yjcm`，两个包使用同一个 Mod ID。开发包的 `yjcm_build_profile.json.txt` 标记为 `publishable=false`。部署正式包时，只从旧开发清单中清理本次包未提供的专用文件。

`E:/sts2mod/三国杀/yjcm` 保留为正式版上传目录。曹操开发成品从专属 artifacts 目录取用，避免误上传。

## 当前内容

- 选人页：用户提供的两套 Spine，转换为4.2.43；背景覆盖视口，主体单独定位，默认循环6秒待机 `play`。点击未被界面按钮遮挡的人物区域时，播放一次12秒点击 `play2`，结束后返回待机。
- 战斗人物：同一人物骨骼的主体副本，去掉独立烟雾、遮罩和背景特效，以及ren1至ren17的前景斧、枪、盾和飘带附件；连同切换/形变轨道移除，防止动画恢复它们。战斗根骨旋正24.14°，现拟合区域530×495（较460×430放大约15%），FACING_X=-1镜像，居中及脚底对齐。单独Selection副本保留选人原画与定位；素材原件不改。
- 卡框：深蓝主体、银色边饰，沿用原生卡框轮廓和透明度。
- 头像、地图图标：使用用户提供的“头像与地图图标.png”；左上角头像场景固定54×54。底部选人按钮使用“选人界面.png”，动态选人立绘保留。原版选人按钮贴图/遮罩均132×195，图像区布局88×130；建议按264×390或528×780近景裁胸像，保持44:65比例，人物应占满画面而非缩小整幅立绘。
- 初始卡组：四杀、四闪、曹操-护驾、威曹操-掇月，共10张；起始生命80、金币99，初始遗物改为军合。其余未制作的火堆、商店、联机手等资源仍暂用战士。
- 卡池：89个独立模型。原50模型保留，新增魏势力表30个设计牌面、衍生沉略及8张隐藏选择牌（39模型）。神典韦、神邓艾加入后神将常规牌共14张；转换和生成保持曹操卡框。详见docs/威曹操魏势力卡牌开发清单.md及设计歧义.md。正式包仍无曹操。
- 护驾：1费技能，升级0费；从当前已解锁、可用于本局的魏国武将牌中随机至多3张选1张加入手牌，本回合免费。排除自身、重复ID和Token；现在包含本批次魏将候选，神将不作为魏将。
- 掇月：1费攻击，可选自身或存活敌人，不能选队友/宠物。每张牌分别记录本回合打出次数，先由玩家弃1张手牌；对自己依次摸1/2/3张，前两次通过原生打出落点返回手牌、第三次不返回；对敌造成次数×6伤害且不返回，军合充足时自动消耗1点使最终伤害翻倍。升级仅6→8，费用、摸牌、回手阈值和军合倍率不变。描述括号显示下一次摸牌量。空手时不打开无解的弃牌选择。
- 军合遗物：正常回合摸牌完成后的原生回合钩子，持有者可选1张手牌，按全部同类型手牌数量+1获得军合，包含所选牌及状态/诅咒等不可打出的牌；可跳过、不弃牌，跳过不触发声音。两段触发语音随机播放，仅使用外观随机数，不消耗战斗随机序列。军合以有图标的计数资源状态显示，跨回合保留、战斗结束按原生清理。2026-11-01按新表增加+1。
- 所有军合强化都应自动尝试消耗；不足则只结算普通效果，不能扣成负数，也不追加失去生命等惩罚。掇月对自己不消耗军合。
- 本轮不接入已经选定的能量图标B/C/B或尚未选定的新卡框概念稿，也不推送GitHub。

通用牌从已验证的董卓生成产物派生，只替换类型、卡池、模型ID和装备生成牌类型，保留素材路径与共享效果。修改原牌后，先运行 `generate_cards.mjs --write`，再运行 `generate_caocao_cards.mjs --write`；不手改曹操 Generated 正文。

素材加工：`WDZ_NODE_MODULES` 指向已安装的 Spine4.2.119开发依赖，运行 `node tools/prepare_caocao_assets.mjs <素材工作区>`。`node tools/preview_caocao.mjs` 可渲染实际 Spine 的选人与战斗预览；图片输出到 `artifacts/reports/weicaocao`，属于开发预览，不是游戏实测。

新增起始素材用 `tools/prepare_caocao_starter_assets.py --relic-source <生成的透明剑图>`，复制用户卡图与头像，将内置image_gen生成的军合遗物图规范为256×256透明PNG；6段MP3（含选中音效）转换为48kHz单声道PCM16 WAV，并在素材/语音素材/威曹操保留WAV。图片全部位于Experimental资源目录；语音仅进assets/experimental/WeiCaoCao/Voice/WeiCaoCao。生成提示词与原图留在忽略的artifacts/design/junhe-20261030。选人音效由专用声音ID经范围限定的SfxCmd补丁播放WAV，不叠放铁甲战士语音，不影响其他声音；卡牌/遗物的军合引用使用[gold]高亮。

`tests/check_caocao_starters.ps1`针对两API运行真实选择/资源/出牌方法的隔离模拟，外部命令以Harmony拦截；验证计数包含选牌、队友隔离、跨回合、先弃后摸/攻击、自动消耗、伤害倍率、升级、回手落点与存档计数，以及军合高亮和选人声音替换范围。测试不读取或修改玩家存档，也不等同于游戏实测。`check_caocao_layout.gd`还核验打包后头像尺寸、遗物256×256透明度和实际贴图加载。`WDZ_NODE_MODULES`指向Spine开发依赖后，可运行`node tests/check_caocao_combat.mjs`遍历242个姿态，验证前景附件在待机/点击动画均不会恢复、旋正数据及选人副本完整。
