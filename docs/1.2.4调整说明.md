# 1.2.4：内伐免费次数限制

- 保持2费、升级1费，摸3弃1与原有类型禁用规则不变；弃置能力牌等其他类型仍不触发内伐状态。
- 弃置攻击牌后，本回合禁用技能牌；免费攻击牌次数等于弃牌结算完成时手中技能牌数。弃置技能牌则反过来统计攻击牌。
- 只按禁用类型统计，不额外计算状态、诅咒、能量不足或其他原因暂时不可使用的牌。只统计一次，后续摸牌、弃牌、生成牌不会重新计算。
- 每使用一张对应类型的牌消耗一次免费次数，包括原本0费或由其他效果免费/自动打出的牌；同次出牌的Replay重复结算只扣一次。不会因预览、队友牌或其他类型的牌扣次数。
- 免费次数为0时恢复正常费用，但禁用效果保留至回合结束。状态悬浮说明显示禁用类型、免费类型和剩余次数；三个状态字段参与原生保存/同步。
- 重复施加沿用原有不叠层行为，重新配置本次禁用类型与次数，不额外累加。

构建/自动回归不等于真实战斗、多人或回放实测。
